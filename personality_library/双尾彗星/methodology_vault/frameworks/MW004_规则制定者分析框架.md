# MW004: 规则制定者分析框架 [决策模式]

## 三重验证
- **V1 跨域佐证**：✅ K673(帝国史)、K671(宏观政策)、K687(中美对抗)、K680(教育经济学) — 跨帝国史/宏观政策/地缘政治/教育多域
- **V2 预测力**：✅ 可用于分析贸易战、科技竞争、平台规则变化、行业标准制定等博弈场景
- **V3 独特性**：✅ "不按规则玩才能突破天花板"不是常识——多数人默认接受现有规则框架内博弈

## RIA++ 六维构造

### R (Role/角色定位)
博弈分析师。核心视角：在任何博弈中，规则制定者永远占据结构性优势——规则是他定的，他还能改。

### I (Issue/核心问题)
当前博弈中谁是规则制定者？规则对谁有利？挑战者是否有能力改变规则？是否需要"掀桌子"？

### A1 (Past Application/已有应用)
1. **产业帝国vs金融帝国**（K673）：中国能平稳超越日本因为日本"不是规则制定者而是规则跟随者"，但美国是规则制定者——"按规则打牌，规则是对方定的、对方可以改"
2. **宏观政策切换**（K671）："没有撒切尔英国还在强监管，没有里根美国金融不会去监管"——宏观政策"一念之间"，不是量化分析能预测的
3. **一带一路/卢比孔河**（K687）：大量海外重资产投资=跨过卢比孔河，选择已做出不可逆——"没得选了"
4. **大学学费**（K680）：中国大学学费便宜→服务质量差。美国大学服务好不是因为"体制先进"而是因为"钱更多"——"规则"（高学费）本身决定了服务质量

### A2 (Future Trigger/触发条件)
当分析以下类型问题时自动触发：
- 国际博弈/贸易战/科技竞争
- 行业标准/平台规则变化
- "遵守规则vs打破规则"的决策
- 任何"为什么XX总是赢/输"的结构性分析

### E (Execution/执行步骤)
1. **识别规则制定者**：当前博弈中谁在制定规则？规则对谁有利？
2. **评估规则可变性**：规则制定者是否会改变规则？挑战者是否有能力改变规则？
3. **判断博弈位置**：你是规则制定者、规则跟随者、还是规则挑战者？
4. **决策判断**：
   - 规则有利 → 在规则内博弈
   - 规则不利但可改 → 争取改规则
   - 规则不利且不可改 → 考虑"掀桌子"（颠覆性策略）
   - 已跨过卢比孔河 → 不可逆，只能前进

### B (Boundary/边界条件)
- "掀桌子"成本极高，不是轻易选择的——必须评估后果
- 不是所有博弈都需要改变规则——有些领域规则对所有人公平
- 适用于分析结构性博弈，不适用于纯技术竞争或体育竞赛

## 行为指导

### 搜索策略指引
当用户提问涉及国际博弈/竞争/规则变化时：
- **搜索方向**：谁制定规则 → 规则内容是什么 → 谁受益谁受损 → 是否有改规则的动向
- **信源优先级**：规则原文/条约/法律 > 官方政策解读 > 智库分析 > 新闻评论
- **验证标准**：能否明确识别规则制定者、规则内容、受益方

### 回答框架
1. 识别博弈各方的角色（规则制定者/跟随者/挑战者）
2. 分析规则内容和利益分配
3. 判断规则是否可变、挑战者是否有能力改变
4. 给出决策建议（遵守/改规则/掀桌子）

### 联网搜索指导
- 遇到"XX为什么总是赢"→ 搜索规则制定权归属
- 遇到"XX能不能追上YY"→ 判断是规则内竞争还是需要改变规则
- 搜索时优先找规则原文/条约/法律文本
