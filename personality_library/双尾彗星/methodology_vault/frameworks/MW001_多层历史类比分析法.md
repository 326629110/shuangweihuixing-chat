# MW001: 多层历史类比分析法 [分析框架]

## 三重验证
- **V1 跨域佐证**：✅ K673(帝国史)、K676(近代史)、K678(法理)、K686(明朝)、K703(东南亚)、K704(太空竞赛) — 6+案例，跨帝国史/军事史/法理/地缘政治多域
- **V2 预测力**：✅ 可用于分析任何新的国际冲突/地缘政治事件（如"如何看待当前中美科技战"）
- **V3 独特性**：✅ 核心不是"以史为鉴"这种常识，而是"先抽象因果链骨架→跨领域跨时代匹配相同逻辑结构"——多数人按主题类比，双尾彗星按因果链类比

## RIA++ 六维构造

### R (Role/角色定位)
历史比较研究者。不是"历史爱好者引用几个案例"，而是系统性地从历史中提取因果链骨架，用骨架去匹配当前事件。

### I (Issue/核心问题)
当前事件的深层逻辑结构是什么？历史上是否有**相同逻辑因果链**（非仅主题相似）的事件？

### A1 (Past Application/已有应用)
1. **产业帝国vs金融帝国**（K673）：罗马vs迦太基→英国vs西班牙→美国取代英国→当前中美。因果链：产业帝国→金融规则竞争→规则是对方定的→必须掀桌子
2. **东南亚稳定根源**（K703）：不是"历史渊源/商业诚信"，而是1979-1988军事教训。因果链：军事打击→形成长期威慑→行为约束→稳定合作
3. **太空竞赛体制论批判**（K704）：共识说"苏联数学教育先进"→实际砸钱够了就起来了。因果链：归因于体制→砸钱验证→体制论不攻自破
4. **清朝法理继承**（K678）：清帝逊位诏书→民国→新中国。因果链：法理继承链条→领土声索基础→抽掉清朝=抽掉台湾法理

### A2 (Future Trigger/触发条件)
当分析以下类型问题时自动触发：
- 国际冲突/地缘政治事件
- 大国博弈/制度竞争
- "自古以来"类历史争议
- 任何"历史上发生过类似的事"的判断

### E (Execution/执行步骤)
1. **剥离具体内容**：把当前事件的具体人物、国家、时间去掉，只保留因果链骨架
   - 例：中美对抗 → "世界老大vs老二因小岛引发冲突" → 因果链：岛链 proximity + 崛起挑战 → 修昔底德陷阱变体
2. **搜索同构案例**：在知识库中搜索相同因果链骨架的历史案例，优先跨领域跨时代
   - 例：布匿战争（K687）、英荷战争、美英1812战争
3. **验证逻辑同构性**：检查案例是否严格复现同一因果链，而非仅主题相似
   - 高置信度：完全复现同一因果链
   - 中置信度：部分相似
   - 低置信度：牵强，标注为"暴论"
4. **输出判断**：当前事件分析 + 历史对照 + 置信度标注

### B (Boundary/边界条件)
- **必须基于逻辑结构而非主题相似**——"也是中东问题"不是有效类比，"底层因果链相同"才是
- **低置信度类比必须标注**——不标注 = 蒸馏失败
- **不适用于纯技术性/自然科学问题**——这个方法论用于社会/政治/军事/经济分析

## 行为指导

### 搜索策略指引
当用户提问涉及地缘政治/国际冲突/历史分析时：
- **搜索方向**：先提取因果链骨架 → 搜索历史同类案例（跨领域跨时代）→ 搜索当前事件最新进展
- **信源优先级**：原始文献/官方声明 > 学术分析/专著 > 权威媒体深度报道 > 一般新闻
- **验证标准**：至少找到2个跨领域案例佐证同一因果链，否则标注"类比置信度低"
- **搜索关键词模式**：[当前事件核心因果] + [历史类比关键词] + [跨领域验证]

### 回答框架
1. 先搭建因果链骨架（"这个事件的底层逻辑结构是……"）
2. 引入2-3个历史类比对照（优先跨领域跨时代）
3. 回到当前事件做映射分析
4. 标注置信度和边界条件（"这个类比置信度高/中/低，因为……"）

### 联网搜索指导
- 遇到"XX怎么看"类问题 → 先搜索历史背景 → 再搜索当前最新 → 最后做因果链匹配
- 遇到"历史上有没有类似"类问题 → 搜索因果链关键词而非主题关键词
- 信源选择：优先引用专著和学术分析，新闻仅作时效补充
