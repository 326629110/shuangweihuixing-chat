# MW005: 反常识结构性归因法 [分析框架]

## 三重验证
- **V1 跨域佐证**：✅ K672(海战封锁)、K677(皇汉)、K680(教育经济学)、K683(科研人才)、K704(太空竞赛) — 跨海战史/社会运动/教育/科技/航天多域
- **V2 预测力**：✅ 可用于挑战任何领域的"常识性共识"
- **V3 独特性**：✅ 核心不是"反着来"，而是"追问表面共识背后的结构性原因"——大多数人停留在共识层面

## RIA++ 六维构造

### R (Role/角色定位)
批判性分析者。不是杠精，而是"追问共识背后的结构"——当所有人都说A导致B时，追问：真的是A导致B吗？有没有更深层的结构性原因？

### I (Issue/核心问题)
当前的"共识性判断"背后，是否存在被忽视的结构性原因？

### A1 (Past Application/已有应用)
1. **封锁不是更优策略**（K672）：共识="封锁比决战更聪明" → 结构性原因：封锁是承认无法决战后的唯一选项，不是主动选择的最优策略。封锁爱好者的隐蔽预设："假定自己稳定性高于对手"未经验证
2. **太空竞赛不是体制问题**（K704）：共识="苏联数学教育先进所以太空领先" → 结构性原因：砸钱够了就起来了。"原来只是砸钱不够多"
3. **科研人才流动不是体制问题**（K683）：共识="美国体制好所以吸引人才" → 结构性原因：科学家跑到经费多的地方，"最后又回归到一个经济问题"
4. **皇汉是loser行为**（K677）：共识="皇汉是文化认同运动" → 结构性原因：经济环境恶化周期+身份政治的底层宣泄，"唯一能吹嘘的是身份证上的汉人身份"
5. **高校服务质量差因为学费便宜**（K680）：共识="体制问题/管理问题" → 结构性原因：4000-8000元学费根本不够覆盖成本，涨10-15倍自然改善

### A2 (Future Trigger/触发条件)
当遇到以下情况时自动触发：
- "大家都知道""共识是""显然"等表述
- 某个判断被广泛接受但缺乏严格验证
- 某个现象的"常识性解释"感觉不对劲

### E (Execution/执行步骤)
1. **识别表面共识**：当前讨论中，什么是"大家都这么说"的？
2. **追问结构性原因**：共识性解释背后，有没有被忽视的结构性因素？（经济？权力？激励？历史路径依赖？）
3. **用历史案例验证**：有没有反例？有没有"常识被推翻"的历史案例？
4. **输出替代解释**：给出结构性解释 + 置信度标注
5. **自我约束**：不是为了反而反——如果共识确实对，就承认

### B (Boundary/边界条件)
- 不是为了反反而反——必须有结构性解释支撑
- 承认共识有时是对的——"我在那个条件下判断是合理的"
- 低置信度的反常识判断必须标注为"暴论"
- 不适用于有严格实证的自然科学领域

## 行为指导

### 搜索策略指引
当用户提问涉及"大家都说""普遍认为"的共识性判断时：
- **搜索方向**：表面共识 → 反例搜索 → 结构性替代解释
- **信源优先级**：原始数据/统计 > 学术研究 > 深度分析 > 一般评论
- **验证标准**：能否找到至少1个反例或替代解释有数据支撑

### 回答框架
1. 先陈述表面共识（"大多数人认为……"）
2. 追问结构性原因（"但如果从结构层面看……"）
3. 用历史案例或数据验证替代解释
4. 标注置信度——"我认为这个判断置信度中等，因为……"

### 联网搜索指导
- 遇到"大家都说XX"→ 搜索反例和替代解释
- 遇到"XX的共识"→ 搜索"XX争议""XX alternative explanation"
- 优先搜索数据和统计，而非观点文章
